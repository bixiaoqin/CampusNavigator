三、核心功能② Dijkstra 最短路径

// Graph::dijkstra() 核心算法 std::vector<int> Graph::dijkstra(int startId, int endId) const { // 初始化 unordered_map<int,double> dist; // 距离表 unordered_map<int,int> prev; // 前驱表 priority_queue<Node,vector<Node>,greater<>> pq; // 最小堆 dist[startId] = 0; pq.push({0.0, startId}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (visited[u]) continue; // 去重 if (u == endId) break; // ★ 提前终止 for (const Edge& e : neighbors(u)) { // 松弛操作 double nd = d + e.weight; if (nd < dist[e.to]) { dist[e.to] = nd; prev[e.to] = u; pq.push({nd, e.to}); } } } // 回溯路径并返回... }

时间复杂度：O((V+E)logV)

V=16, E=20 时：< 0.1ms 瞬时响应

存储结构：邻接表（unordered_map + vector）

优化：提前终止 + visited去重

三、核心功能③ 角色漫游 & 自动导航

手动漫游

  • WASD / 方向键 控制角色移动
  • 30FPS moveTimer 定时器驱动
  • keyPressEvent 记录按键状态
  • 每帧根据状态累加位移
角色外观：红圆点 + 白色方向箭头
Z=10 保证在所有元素最上层

自动导航动画

  • Dijkstra 计算出路径后启动 navTimer
  • 沿路径逐段线性插值移动
  • 速度：默认 120 像素/秒
  • 到达终点自动停止并提示
  • ★ 导航中按 WASD 可随时中断接管
三定时器协作：
moveTimer_(手动33ms) ↔ navTimer_(自动33ms) 互斥
auxTimer_(辅助100ms) 独立更新迷你地图

四、2.5D 斜投影渲染 ★ 技术创新

传统做法 vs 本项目

方案效果技术难度
2D 扁平矩形普通低
本项目：2.5D 斜投影立体盒子中
真 3D (OpenGL)完全立体极高

核心原理

  • 同一建筑色派生三档明度
  • 屋顶（原色最亮）→ 右墙(darker 120) → 前墙(darker 150)
  • 模拟左上方光源产生立体感
  • 地面半透明阴影增强空间感
坐标示意：
┌─────────────────┐
│ (0,0) 屋顶(W×H) │ W=100 H=60
│ ╲ 前墙 │ S=10 D=16
│ ╲ │
│ ╲ 右墙 │
│ (S,H+D)───────┘
└─────────────────┘

绘制顺序：
①地面投影 → ②右墙 → ③前墙 → ④屋顶
（从后往前，Painter's Algorithm）

核心功能④ SQLite 数据库管理

设计模式：单例模式 Singleton

  • 全程只需一个数据库连接
  • SQLite 是文件型数据库
  • 多连接反而有问题
  • DatabaseManager::instance()

SQL 注入防护

  • 所有操作使用 prepare() 预处理语句
  • bindValue() 参数绑定
  • Qt 自动转义特殊字符
